## Gemini Nano Banana Pro

Generate or edit images with Gemini Nano Banana Pro (Gemini 3 Pro Image,
`gemini-3-pro-image`), Google's image model for complex instructions,
brand consistency and high-fidelity text.

Add a Gemini API key in the plugin settings, then use prompts such as:

> Generate a poster for a jazz night, with the title "Blue Hour"

> [Image Attachment] Turn this sketch into a product photo

The plugin supports new images, edits from selected attachments (up to 14
reference images), edits from the previous plugin output, aspect ratio (1:1,
2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9) and 1K/2K/4K output size.
